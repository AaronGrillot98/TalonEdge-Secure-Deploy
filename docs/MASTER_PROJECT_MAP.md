# Master Project Map

TalonEdge V2 combines three portfolio ideas into one flagship project.

## AeroSentinel Layer

Represents edge telemetry, security findings, policy checks, and operator reporting.

## FieldDeploy-Kit Layer

Represents forward deployment, limited connectivity, recovery procedures, runbooks, Docker, Terraform, and GitHub Actions.

## Artifact Trust Inspector Layer

Represents artifact validation, SHA256 verification, manifest checking, signature status, SBOM presence, and trust scoring.

## One-sentence story

TalonEdge is a forward-deployed secure edge platform that validates software artifacts, evaluates remote node telemetry, handles degraded connectivity, and publishes a trusted operational report through a real AWS CI/CD pipeline.
