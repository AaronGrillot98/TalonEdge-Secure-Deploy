BEGINNER FRIENDLY AWS DEPLOYMENT GUIDE

TalonEdge Secure Deploy V2

This guide turns the project into a real AWS-backed SecDevOps portfolio piece using GitHub Actions, Terraform, S3, CloudFront, Docker, and OIDC.

Plain-English Goal

You are building one master project, not several scattered ones. TalonEdge combines AeroSentinel, FieldDeploy-Kit, and Artifact Trust Inspector into one flagship repo. It proves you can secure, validate, deploy, and operate a forward-deployed edge system.

What you will end with

  • Python CLI that scans telemetry and artifacts
  • HTML operator report
  • Docker runtime
  • GitHub Actions test pipeline
  • Terraform-created AWS infrastructure
  • Private S3 bucket
  • CloudFront HTTPS URL
  • GitHub Actions AWS deployment using OIDC

Step 1: Create your GitHub repo

  1. Unzip this folder.
  2. Create a new GitHub repository named TalonEdge-Secure-Deploy.
  3. Upload all files from this folder.
  4. Commit to the main branch.
SCREENSHOT: GitHub repo home page showing README and folders.

Step 2: Test locally

python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m pip install -r requirements-dev.txt
python -m pytest tests
python -m talonedge demo

Windows activation command:

.venv\Scripts\activate
SCREENSHOT: Terminal showing tests passed and TalonEdge demo complete.

Step 3: Generate the report

mkdir -p reports
python -m talonedge simulate --output reports/index.html

Open reports/index.html in your browser.

SCREENSHOT: TalonEdge Operator Report open in your browser.

Step 4: Test Docker

docker build -t talonedge-secure-deploy .
docker run --rm talonedge-secure-deploy
SCREENSHOT: Docker build and run success.

Step 5: Configure AWS

Use a normal AWS account. You need permission to create S3, CloudFront, IAM roles, IAM policies, and OIDC provider resources.

Do not paste AWS secret access keys into GitHub. This project uses OIDC instead.

Step 6: Run Terraform

cd infra/aws
terraform init
terraform plan -var="github_repo=YOUR-GITHUB-USERNAME/TalonEdge-Secure-Deploy"
terraform apply -var="github_repo=YOUR-GITHUB-USERNAME/TalonEdge-Secure-Deploy"

Type yes when Terraform asks for approval.

Save these outputs:

  • s3_bucket_name
  • cloudfront_distribution_id
  • cloudfront_url
  • github_actions_role_arn
SCREENSHOT: Terraform apply complete with outputs visible.

Step 7: Add GitHub Actions variables

Go to GitHub repo → Settings → Secrets and variables → Actions → Variables.

Add:

AWS_REGION = us-east-1
AWS_ROLE_ARN = paste github_actions_role_arn
S3_BUCKET = paste s3_bucket_name
CLOUDFRONT_DISTRIBUTION_ID = paste cloudfront_distribution_id
SCREENSHOT: GitHub variables page showing variable names only.

Step 8: Deploy

Push a commit to main, or manually run the workflow from GitHub Actions.

git add .
git commit -m "Deploy TalonEdge to AWS"
git push origin main

Open GitHub → Actions → Deploy TalonEdge Report to AWS.

SCREENSHOT: GitHub Actions deployment succeeded.

Step 9: Open the live report

Open your Terraform output named cloudfront_url.

SCREENSHOT: Live TalonEdge report on CloudFront HTTPS URL.

What to say in interviews
