TalonEdge Secure Deploy Platform

Beginner-friendly setup guide for an Anduril-targeted SecDevOps flagship project.

What you are building

You are building a small secure edge-deployment lab. It checks whether a deployment artifact can be trusted, reads edge telemetry, applies policy-as-code, scores risk, and creates an HTML operator report.

Apps/tools you need

  • GitHub account
  • Python 3.10 or newer
  • VS Code on PC/Mac, or GitHub Codespaces on iPhone/iPad
  • Optional: Docker Desktop

iPhone/iPad path

Use GitHub Codespaces. Upload this folder to a GitHub repo, open the repo in Codespaces, then run the commands below in the Codespaces terminal.

Step 1: Open the project folder

cd TalonEdge-Secure-Deploy
Screenshot 1: Take a screenshot of the file tree showing README.md, src, policies, artifacts, infra, and .github.

Step 2: Create the Python environment

python -m venv .venv
source .venv/bin/activate

On Windows PowerShell use:

.venv\Scripts\activate

Step 3: Run the full demo

python run_talonedge.py demo
Screenshot 2: Capture the terminal output showing artifact trusted, risk level, findings, and report path.

Step 4: Run the scan command

python run_talonedge.py scan
Screenshot 3: Capture the scan output showing expected hash, actual hash, and risk level.

Step 5: Open the report

Open this file:

dist/talonedge_report.html
Screenshot 4: Capture the report hero section and policy findings table.

Step 6: Run tests

python -m unittest discover -s tests -p "test_*.py"
Screenshot 5: Capture passing tests.

Step 7: Push to GitHub

git init
git add .
git commit -m "Initial TalonEdge secure deploy project"
git branch -M main
git remote add origin YOUR_GITHUB_REPO_URL
git push -u origin main
Screenshot 6: Capture GitHub Actions passing after push.

How to explain this in an interview

“I built this to prove I can connect security, deployment, automation, and operations. It models a forward-deployed edge node where software artifacts need to be verified, telemetry may be delayed, and operators need clear risk reporting.”
